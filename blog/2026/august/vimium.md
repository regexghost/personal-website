You should use the [Vimium](https://vimium.github.io/) extension. It adds vim bindings to your web browser. I don't use vim (I know how to in theory, just never made the switch), but this extension is great regardless of if you actually use vim.

The first big advantage is bringing certain actions onto the main keyboard keys, notably page up and page down, which are now `u` and `d`. Much easier to hit than `PageUp` or `PageDown`, plus my keyboard doesn't actually have those keys. Hitting `gg` to go to the top is also really handy. My favourite feature of Opera back when I used it on Windows was that you could click on the active tab in the tab bar to go to the top.

The second advantage is the link-clicking mode. If you hit `f` (or `Shift+f` for new tab), it will show a key combination next to links. The key combination is normally something like `d` or `sf`, easy to hit with just your left hand. This is so much faster for navigating around pages. I use it a lot just to re-focus the search bar on a website.

I have disabled the extension on YouTube, as YouTube already has inbuilt key-bindings which this breaks (`/` to go to search bar, `f` for fullscreen etc)
