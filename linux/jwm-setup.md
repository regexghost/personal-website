## Keybinds

| Shortcut | Function | Notes |
| :-: | :-: | :-: |
| `Super+/` | Minimise | |
| `Super+'` | Maximise | |
| `Super+Shift+r` | Resize window | |
| `Super+Shift+q` | Close window | |
| `Super+.` | Desktop right | |
| `Super+,` | Desktop left | |
| `Super+Shift+.` | Move window to desktop right | |
| `Super+Shift+,` | Move window to desktop left | |
| `Super+1/2/3/4` | Desktop 1/2/3/4 | No equivalent for move window |
| `Super+Right` | Tile window right | |
| `Super+Left` | Tile window left | |
| `Super+Up` | Tile window top | |
| `Super+Down` | Tile window bottom | |
| `Super+Shift+Right` | Tile window bottom right | |
| `Super+Shift+Left` | Tile window top left | |
| `Super+Shift+Up` | Tile window top right | |
| `Super+Shift+Down` | Tile window bottom left | |
