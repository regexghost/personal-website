A set of life-organisation cli utilities (re)written in Golang:

* `log` - diary/captain's log
* `schedule` - weekly timetable
* `days` - countdown to events
* `money` - spending tracker
* `cal` - calorie and exercise tracker

I originally wrote these as bash scripts, then re-wrote in Golang, re-re-wrote in Rust and now I've settled on using Golang.
